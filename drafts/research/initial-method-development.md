# Initial method development

*Development record. Not a novelty study. Not a naming brief. Not
field validation.*

**Status of the method:** initial application method. Not independently
validated. The five-move grouping is a practical collapse of existing
guidance, **not research-proven**.

---

## Derived from corpus

- Thesis: specialization remains; org boundaries as routine delivery API
  are the target.
- Unit: engineering system scoped to a class of intent.
- Accidental vs intentional friction (design doctrine).
- Encode what is repeatable; collaborate on what is novel. Repeated work
  is a signal, not a verdict.
- Authority ≠ execution; ownership ≠ routing; composition does not
  transfer domain authority.
- Human realization is valid.
- Learning informs, does not mandate.
- Existing six activities: trace, evaluate, identify, decide, design,
  operate.

## Clarified for application

- Entry conditions (when this method is useful, and when it is not).
- Five moves as the **front door**: Scope, Trace, Diagnose, Intervene,
  Observe. Identify / encode / design remain **depth**.
- Always vs conditional vs advanced diagnostics.
- Wait/friction *why* as overlapping hypotheses, not a waste score.
- Wrong-success as an explicit question.
- One optional application record (thinking aid, not compliance).
- Stop rule (bounded analysis is enough).
- Intervention menu including change nothing; not automatically
  platform/automation.

## Unvalidated

- Whether ~30 minutes to learn / ~60–120 minutes for a first pass is
  realistic. Public docs treat these as **design goals**, not evidence.
- Whether the five-move grouping holds after field use (it may collapse
  or reorder).
- Practical value of the method as a whole.

## Open questions

- Who funds encoding and composite stewardship (already in corpus open
  questions).
- How consumer vs domain-authority disagreement is closed in practice.
- Federation as a method, not only architecture.

## Deliberately not added

New principles, conceptual-model stages, path owner, Convergence team,
scoring, uniqueness claims, field evidence we do not have.

## Theory contradictions found

None. Frozen core unchanged.
