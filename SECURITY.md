# Security policy

Use the company reporting path:
[OpsDevCode SECURITY](https://github.com/opsdevcode/.github/blob/main/SECURITY.md).

**Do not open a public issue for a vulnerability** in OpsDevCode product
runtimes here. This repository is a public methodology. Report product
vulnerabilities on the owning product repo.

For this docs repo: GitHub Security Advisories or **security@opsdevcode.com**.
