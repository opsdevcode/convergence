files from drawing tools). Nothing there is required yet.

Traditional delivery shows specialties connected by handoffs. Converged
Engineering shows the same specialties contributing to shared capabilities.
Do not read the second diagram as a merger of roles.

These diagrams are arguments, not network designs. If a diagram starts to
look like a product architecture, it belongs in a later reference
architecture draft, not here.
