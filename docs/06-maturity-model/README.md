# Maturity model

**Status:** Placeholder. No scores, levels, or certification.

Capability maturity is **not** automation maturity. Human-realized
capabilities can be highly mature. See
[Capability characteristics](../02-capabilities/capability-characteristics.md)
for independent dimensions (explicitness, repeatability, human judgment,
organizational independence, composability, governance, observability).

Do not build an assessment framework here until those dimensions are
argued in the open.
