# Principles

These documents are working doctrine for v0.1. Changing a Major Principle
requires an [RFC](../../rfcs/README.md).

Foundational reasoning that is **not** a Major Principle is in
[Design doctrine](../00-foundations/design-doctrine.md). Capability
mechanism guidance stays under [02 Capabilities](../02-capabilities/README.md).

The six Major Principles below are the v0.1 set. Do not add a seventh to
fill a gap. Park unresolved issues in
[Open questions](../00-foundations/open-questions.md).
