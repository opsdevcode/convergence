# Anti-patterns

**Status:** Placeholder for v0.7.

Failure modes already named elsewhere, to expand later:

- Portal as ticket router
- "You build it, you run it" without encoded reliability or security
- Capability as a team rename with the same queue
- Agent with org-wide credentials and no contracts
- Measuring platform success only as developer satisfaction
- Treating Converged Engineering as a synonym for Platform Engineering or
  DevOps
- Treating Convergence as a new specialty or "Convergence Engineering" team
- Treating a capability catalog as a complete solution to organizational
  problems
- Claiming specialists are no longer needed

An anti-pattern page should describe why the move is tempting, what it
costs, and what to do instead, without mocking the people who did the
tempting thing for a real reason.
