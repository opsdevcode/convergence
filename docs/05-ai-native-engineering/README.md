# AI-native engineering

AI is **not** the reason Convergence exists.

**AI does not create the need for Convergence. It exposes the cost of not
having it.**

Humans, products, software systems, automation, and authorized AI agents
are possible [capability consumers](../02-capabilities/capability.md).
They do not have equal judgment or rights. They should not have to
navigate equal org charts.

Agentic engineering increases the value of **explicit** capabilities
because agents cannot reliably depend on tribal routing: hallway names,
Slack channels, "that team handles this," or a ticket type.

**Your organizational structure should not become your software delivery
API.**

## What an agent changes, and what it does not

| An agent changes | An agent does not change |
| --- | --- |
| The [experience](../02-capabilities/experience.md) a capability needs | What the capability is |
| How explicit discovery and contracts must be | The domain authority behind it |
| How much can be left to inference (almost nothing) | Who is accountable for the outcome |
| The urgency of stated blast-radius limits | The requirement to govern it |

An agent consumes the [same conceptual set](agents-as-capability-consumers.md)
of capabilities as everyone else. It does not get a separate graph, a
separate org, or a lighter authorization story.

## The one rule that survives everything else

**Invoking a capability does not grant authority.** Agents act under a
principal and privilege the organization already decided, and they must
not bypass governance. Everything else in this section elaborates that
sentence.
