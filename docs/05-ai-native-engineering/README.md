# AI-native engineering

Humans, products, software systems, automation, and AI agents are all
**capability consumers**. They do not have equal judgment or equal rights.
They should not have to navigate equal org charts.

An agent should not need to know which team owns networking, who approves
identity, which Slack channel owns Kubernetes, or which ticket queue
provisions databases. It should discover and invoke authorized, governed
capabilities. That is the same rule as for humans, applied where hallway
knowledge cannot substitute.

**Your organizational structure should not become your software delivery
API.**

That sentence was already true for humans. It is sharper for agents. An
agent cannot attend your CAB, learn that "ask Priya for prod," or interpret
an undocumented wiki. If the only interface to expertise is a team, agents
will either be blocked or they will be given broad credentials and hoped
for the best. Both are failure modes.

See [Agents as capability consumers](agents-as-capability-consumers.md).
