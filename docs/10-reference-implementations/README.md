# Reference implementations

**Status:** Placeholder. No implementation defines Convergence, Converged
Engineering, or the capability model.

This folder will list **examples** of systems, internal platforms, or open
source projects that attempt to encode engineering expertise as reusable,
governed capabilities, or that otherwise illustrate Converged Engineering.
Listing is not endorsement. Absence is not condemnation.

Rules for anything added here:

1. The implementation is not the definition of Convergence or Converged
   Engineering.
2. Adopting the model does not require adopting the implementation.
3. Descriptions should map to terms in this repository (Convergence,
   Converged Engineering, capability, contract, consumer, graph) so readers
   can compare, not so they can buy.

Implementations may be incomplete, opinionated, or tied to a particular
stack. That is expected. The body of knowledge stays vendor-neutral.
